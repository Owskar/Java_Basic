# Java Basics

A collection of Java learning examples and exercises, organized by language topic.

## Topics

The repository includes examples covering basic syntax, arrays, strings, collections, object-oriented programming, abstraction, interfaces, polymorphism, exception handling, synchronization, and switch statements.

## Run an example

Install a JDK, then compile and run a Java source file from its topic directory:

```bash
javac Example.java
java Example
```

Replace `Example.java` and `Example` with the name of the source file and its class.
